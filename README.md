# Innominds public assets

Public images used by Innominds product READMEs (PyPI can only display images served from public URLs).

## iHarmony™

Images for the [iHarmony](https://pypi.org/project/iharmony/) README on PyPI.

| File | Used for |
|---|---|
| `iHarmony/hero.png` | README banner |
| `iHarmony/capabilities.png` | Capability overview |
| `iHarmony/workflow.png` | "How it works" strip |
| `iHarmony/footer.png` | Innominds footer |

The `.svg` files next to them are the sources. Generated by `scripts/build_readme_assets.py` in the iHarmony
repository; do not edit by hand.

`readme/` holds the earlier innoHarmony images. They stay for README versions already published on PyPI
and as the source of the Innominds wordmark for TruVelocity; new iHarmony releases use `iHarmony/`.

## TruVelocity™ (AI-Led QE Accelerators)

Images for the README of [AI_Led_QE_Accelerators](https://github.com/ShanInnominds/AI_Led_QE_Accelerators), in the same Innominds style.

| File | Used for |
|---|---|
| `truvelocity/hero.png` | README banner |
| `truvelocity/capabilities.png` | Four QE layers and agent availability |
| `truvelocity/workflow.png` | "The TruVelocity QE flow" strip |
| `truvelocity/footer.png` | Innominds footer |

Rendered at 2560px wide from the HTML in `truvelocity/src/` (headless Edge or Chrome screenshot); the Innominds wordmark is cropped from `readme/hero.png` and `readme/footer.png`. Edit the HTML and re-render rather than editing the PNGs.
